# Antigravity observer adapter

This is a thin loader for the temporary `antigravity-local` registration in `AGENTS.md` **Inference
routing**. It is not a plugin manifest and does not install tools, create a schedule, or grant writes.
The registration is disabled pending native verification; this file alone does not activate it.
The native Markdown pointer is `.agents/rules/inference-routing.md`. Configure its activation in
Antigravity's Rules panel only after the registration's probes pass; no undocumented rule-frontmatter
keys are assumed. [Native rules documentation](https://antigravity.google/docs/rules-workflows/)
defines that workspace path and activation modes.

After verification, give a native observer this instruction:

> Read the consumer AGENTS.md Inference routing section and its reviewed policy/runtime registration.
> Read the pinned portfolio-maintenance skill's references/inference-routing.md bounded delegation
> contract. The assigned static repository question is the complete scope; do not invoke the
> portfolio run loop or expand this task into portfolio preemption, surveying or artifact delivery.
> The task packet supplies an immutable source revision, permitted read surfaces and a bounded
> output. If the policy, registration, native billing/model controls, or read-only boundary cannot
> resolve, report the capability gap and do not dispatch. Return a compact dependency/source map
> with evidence locations and unresolved questions. No repository/Git writes, installs, builds,
> formatters, forge mutations, live cluster access or write-capable MCP calls. No child delegation,
> model substitution or Fable-family inference. Do not infer permissions from another harness.

Configure supported native tools and plugin fields only after their actual surface/version is
verified. Native `mcp_config.json` is not interchangeable with Claude's `.mcp.json`; no model API
service or new MCP dependency is needed. The canonical role and skills remain in the reviewed
plugin, and all deployment rules remain in AGENTS.md and its policy.
