## What shipped

### KSail

**Fixed**

- New clusters on Talos v1.14 start their network again, because the Calico network no longer waits on a volume driver Talos removed. Existing clusters pick the setting up on their next update; a cluster upgrading from an older Talos still needs it applied before the upgrade. ([#8280](https://github.com/devantler-tech/ksail/pull/8280))
- Homebrew installs now include shell completions. ([#8162](https://github.com/devantler-tech/ksail/pull/8162))
- The Linux and Windows desktop downloads now include the app's interface. ([#8284](https://github.com/devantler-tech/ksail/pull/8284))
- Local Kind clusters inside other clusters no longer clash over Docker network addresses. ([#8163](https://github.com/devantler-tech/ksail/pull/8163))

**New**

- KSail can now generate Flux webhook receivers, health checks on Helm releases and signed-commit checks on Git sources. ([#8193](https://github.com/devantler-tech/ksail/pull/8193), [#8189](https://github.com/devantler-tech/ksail/pull/8189), [#8191](https://github.com/devantler-tech/ksail/pull/8191))
- The command that removes one chosen local cluster connection is now a regular command, no longer an experiment. ([#8218](https://github.com/devantler-tech/ksail/pull/8218))

### Platform

**New**

([#5903](https://github.com/devantler-tech/platform/pull/5903), [#5958](https://github.com/devantler-tech/platform/pull/5958), [#5959](https://github.com/devantler-tech/platform/pull/5959))

**Fixed**

- Web pages that talk to their server in gRPC-web, such as the kagent page, now load their data instead of coming back empty. ([#5961](https://github.com/devantler-tech/platform/pull/5961))
- A worker machine restart now checks that all five current databases are healthy first, and storage volumes missing a copy get room to rebuild it. ([#5980](https://github.com/devantler-tech/platform/pull/5980), [#5969](https://github.com/devantler-tech/platform/pull/5969))
- Sign-in now runs on a Dex build made from source and checked against its publisher. ([#5954](https://github.com/devantler-tech/platform/pull/5954), [#5939](https://github.com/devantler-tech/platform/pull/5939))
