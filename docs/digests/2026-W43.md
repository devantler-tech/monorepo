## What shipped

This is the first weekly digest. It covers 12 to 18 October.

### KSail

**Fixed**

- `ksail update` now upgrades Cilium, Argo CD, metrics-server and the Hetzner drivers when their settings change, instead of leaving the old version running. ([#7723](https://github.com/devantler-tech/ksail/pull/7723), [#7820](https://github.com/devantler-tech/ksail/pull/7820), [#7705](https://github.com/devantler-tech/ksail/pull/7705), [#7768](https://github.com/devantler-tech/ksail/pull/7768))
- An EKS cluster whose local state was lost can be managed again, and AWS no longer rejects its control-plane upgrades. ([#7274](https://github.com/devantler-tech/ksail/pull/7274), [#7746](https://github.com/devantler-tech/ksail/pull/7746))
- Exporting images from a cluster with worker nodes now works, because KSail reads them from the node that holds them. ([#7824](https://github.com/devantler-tech/ksail/pull/7824))

**New**

- vCluster clusters can run Kubernetes 1.37. ([#7815](https://github.com/devantler-tech/ksail/pull/7815))

**Improved**

- New readers get a short first-use walkthrough, and the docs show every distribution and provider combination that works. ([#7704](https://github.com/devantler-tech/ksail/pull/7704), [#7834](https://github.com/devantler-tech/ksail/pull/7834))
