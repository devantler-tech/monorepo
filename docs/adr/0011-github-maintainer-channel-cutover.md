## Decision

The maintainer accepted GitHub notifications and replies in #4484 and directed completion of the
remaining rollout. The daily unanswered-only digest from ADR 0010 is the unattended channel.
This supersedes ADR 0009's email-arrival prerequisite and Slack exception for maintainer asks.
It also supersedes the older separate App-comment publisher proposed in #4054; no additional App,
credential or second inbox is needed for this accepted workflow.

The reviewed workflow assigns urgent asks as github-actions[bot], with a global cap of three per
UTC day and durable assignment-history accounting. Daily and urgent delivery share serialization.
An authority-parked PR links its open ask issue; missing intake remains actionable. Agents read and
reconcile authenticated replies, including older closed digest threads, before sending anything.

Quiet days send nothing and retain their changelog. Answered asks are never repeated. Older digest
threads remain available; closing them for tidiness must not generate extra notifications.
One Codex writer prepares each dated changelog through the shared claim and normal review path.
The Improver reviews feedback and digest quality weekly.

Slack retirement includes a final private sweep of every self-DM parent and advertised reply thread,
with answers reconciled on the original work. Historical receipts remain readable; new Slack
receipts are refused by the composer. Platform alert routing is a separate product concern.
Runtime-local permission removal is prepared for the maintainer to apply, without widening access
or editing another runtime's configuration.

## Private communication

Public asks never contain confidential incident or financial details. Confidential direction uses
the native interactive tool until an approved private destination exists. An unattended run without
one fails closed on that communication. Spend remains disabled, and its private channel remains
UNRESOLVED. The separate mail-service proposal in platform#5030 is not a prerequisite for the
accepted public GitHub channel, nor permission to enable spend stewardship.

## Implementation constraints

Sweep the whole urgent queue: default GitHub concurrency can replace pending runs. Workflow-token
label events do not start another workflow, so bot-created urgent asks require explicit dispatch.
See [GitHub concurrency](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency)
and [workflow-token events](https://docs.github.com/en/actions/concepts/security/github_token).
